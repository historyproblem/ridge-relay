# Проверка Ridge Relay

Дата: 2026-10-09. Среда: macOS, Node.js 24.19.0, TypeScript 5.9.3, Vite 7.3.7; зависимости установлены pnpm 11.25.0 по lockfile.

## Выполнено

- Проверка TypeScript всех исходников и тестов: без ошибок.
- Сборка Vite клиента и TypeScript сервера: успешна; клиентский JavaScript около 511 KB до gzip.
- `tests/simulation.test.ts`: 10 тестов прошли. Движение, торможение при устаревшей команде, наклон, отдельное наведение, препятствия и крутые склоны; урон, уничтожение и возрождение; swept-попадания, точное пересечение heightfield; разрушение/удаление коллайдера/поздний вход; положение ствола; управление и ограничения дрона, завершение и перезарядка; попадание по дрону/авария/потеря танка/отключение; восстановление места и счёта/таймаут/пятый игрок; некорректные команды.
- `tests/network.test.ts`: один сценарий с настоящими WebSocket-клиентами и временным сервером на loopback прошёл. Два клиента видят движение и наведение, получают одинаковые HP после выстрела, уничтожение/возрождение и состояние разрушенного здания. Третий клиент получает разрушение в welcome. Наблюдатель получает появление и движение дрона. Отключение убирает дрон, переподключение сохраняет ID и счёт. Пятый игрок получает `full`, некорректное сообщение получает `invalid`.
- Всего: **11 PASS, 0 FAIL**.
- Собранный сервер запущен на `0.0.0.0:3000`. Во встроенном браузере отрисованы стартовый экран и 3D-поле, клиент вошёл под именем Alpha, появился танк, HUD показал `LAN connected`, здоровье и счёт.

## Требует отдельной проверки

- Два физических компьютера в одной Wi-Fi сети: оборудование и второй компьютер в этой сессии не подключались. Брандмауэр, гостевая изоляция и реальная задержка Wi-Fi проверяются по инструкции README.
- Ручное прохождение полного сценария боёв на двух устройствах, удобство мыши/Pointer Lock в разных браузерах и производительность при четырёх аппаратных клиентах.

Автоматические сетевые тесты проверяют симуляцию и согласованность сообщений; они не заменяют проверку браузерной графики на двух физических устройствах.
