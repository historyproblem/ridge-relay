# Ridge Relay

Рабочий прототип аркадного танкового боя для **2–4 игроков в одной Wi-Fi/LAN сети**. Один компьютер запускает Node.js-сервер, остальные открывают его адрес в браузере. Разрушаемый посёлок, холмы и укрытия, независимо вращающаяся башня, снаряды, возрождение и управляемый разведывательный FPV-дрон.

Все модели и эффекты созданы программно. При игре нет CDN, облачных сервисов, аккаунтов или загрузок внешних ресурсов. После установки зависимостей можно отключить интернет, сохранив локальную сеть.

## Быстрый запуск

Нужны **Node.js 22.12+ (рекомендуется Node.js 24 LTS)** и настольный браузер с WebGL, клавиатурой и мышью.

```sh
git clone git@github.com:historyproblem/ridge-relay.git
cd ridge-relay
npm install
npm run build
npm start
```

Открыть **http://localhost:3000** на хосте. Сервер выводит адреса LAN, например `http://192.168.1.42:3000`. На других компьютерах открыть этот LAN-адрес, ввести разные позывные и нажать **Enter the valley**.

Для установки точно по сохранённому lockfile можно вместо `npm install` использовать pnpm:

```sh
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm run build
pnpm start
```

Разработка с Vite и тем же сервером/портом:

```sh
npm run dev
```

Проверки:

```sh
npm run typecheck
npm test
npm run build
```

Другой порт, macOS/Linux:

```sh
PORT=3100 npm start
```

PowerShell:

```powershell
$env:PORT = '3100'
npm start
```

Остановка — `Ctrl+C` в терминале хоста. Мир и счёт хранятся в памяти: перезапуск сервера начинает новую сессию.

## Подключение по Wi-Fi

1. Подключить все компьютеры к одной обычной сети Wi-Fi или к одному LAN. Гостевая сеть часто включает **AP/client isolation**, запрещающую устройствам общаться друг с другом. Если хост недоступен, проверить этот параметр роутера или перейти в основную сеть.
2. Взять LAN IPv4 из вывода сервера. Если есть VPN, Docker, Parallels или несколько интерфейсов, использовать адрес именно Wi-Fi-интерфейса. `localhost` на втором компьютере обозначает второй компьютер.
3. Проверить IP вручную:
   - macOS: `networksetup -listallhardwareports` показывает интерфейс Wi-Fi; для него выполнить, например, `ipconfig getifaddr en0`.
   - Windows: `ipconfig`, поле IPv4 в разделе активного Wi-Fi адаптера.
   - Linux: `ip -4 addr`, адрес активного беспроводного интерфейса.
4. На хосте открыть `http://localhost:3000/health`: должен быть JSON с `status: "ok"`. На втором компьютере открыть `http://<IP-хоста>:3000/health` и затем корневой адрес игры.
5. В брандмауэре хоста разрешить входящие подключения **Node.js / TCP 3000** для используемой локальной/частной сети. В Windows проверить профиль «Частная сеть»; в macOS — настройки Firewall и разрешение для Node. Если выбран другой `PORT`, разрешить его. Сервер слушает `0.0.0.0`; HTTP и WebSocket используют один порт.
6. В PowerShell можно проверить порт: `Test-NetConnection <IP-хоста> -Port 3000`. На macOS/Linux: `nc -vz <IP-хоста> 3000`.

Если игра открывается, но соединение теряется, проверить, что хост не уснул, сервер продолжает работать, IP не поменялся, а прокси/VPN не перехватывает локальный WebSocket `/ws`. При смене IP открыть новый адрес.

Никакого проброса порта роутера для LAN не нужно. Этот прототип рассчитан на доверенную локальную сеть.

## Управление

| Действие | Танк | FPV-дрон |
| --- | --- | --- |
| W / S | Разгон вперёд / назад | Полёт вперёд / назад |
| A / D | Поворот корпуса влево / вправо | Смещение влево / вправо |
| Мышь | Камера и направление прицеливания | Горизонтальный курс и взгляд |
| Левая кнопка мыши | Выстрел, удержание повторяет после перезарядки | Не используется |
| Space / Ctrl | Не используются | Подъём / снижение |
| F | Запуск одного разведывательного дрона | Завершение полёта и возврат |
| Esc | Освобождение мыши и меню | Освобождение мыши и меню |

Щёлкнуть по полю, чтобы захватить мышь. После Esc нажать **Return to the field**. Если браузер не разрешает Pointer Lock по LAN HTTP, удерживать правую кнопку мыши для изменения взгляда. Выстрел по-прежнему выполняется левой кнопкой.

Белый крест — точка наведения камеры. Янтарная точка — направление **фактического ствола**, с учётом поворота башни, наклона корпуса и ограничения углов. Пока башня доворачивается, точки могут расходиться. Точка не компенсирует небольшой гравитационный спад снаряда на дальних дистанциях.

Во время FPV танк немедленно останавливается и остаётся уязвимым. Полёт: 35 секунд, дальность 65 м от танка, потолок 35 м над уровнем земли под танком. Столкновение с землёй, зданием, каменным укрытием или границей уничтожает дрон. По нему можно попасть из орудия. После возврата, аварии, уничтожения танка или отключения игрока дрон удаляется; перезарядка — 10 секунд. Дрон не вооружён.

Меню не останавливает сервер. Потеря фокуса/скрытие вкладки снимает команды движения и стрельбы. При потере связи сервер прекращает старую команду через 0,4 секунды. Клиент автоматически переподключается; токен восстановления хранится в `sessionStorage` конкретной вкладки. Место и счёт сохраняются 30 секунд, затем отключённый танк удаляется. «Leave arena» тоже отключает соединение; место освобождается после этого интервала.

## Архитектура и упрощения

- **Авторитетный сервер:** фиксированная симуляция 60 Гц. Только сервер меняет координаты, скорости, здоровье, попадания, разрушения и счёт. Клиент посылает оси управления, желаемые углы, выстрел и счётчик переключения дрона. Входящие сообщения проверяются по типам и диапазонам; поля вроде клиентского `hp`/`x` не используются.
- **Сеть:** WebSocket `/ws` и HTTP на одном сервере. Полные снимки мира идут 20 раз/с. Welcome содержит весь текущий мир, включая разрушенные здания. Клиент посылает команды 30 раз/с; положение и углы всех движущихся объектов интерполируются с буфером 100 мс. Телепорт при возрождении не интерполируется. Клиентского предсказания и компенсации задержки нет; при нормальной LAN задержке остаётся небольшая задержка управления.
- **Карта:** 160 × 160 м, детерминированный треугольный heightfield с шагом 2 м. Высота и треугольники одинаковы на клиенте и сервере. Холмы закрывают обзор и выстрелы; слишком крутые склоны ограничивают движение. Камера сокращает дистанцию перед укрытиями и держится над землёй.
- **Танки:** аркадная кинематика, разгон/торможение, круговые коллайдеры при движении; ориентированный объём корпуса при попадании. Это упрощённые формы, без rigid-body физики, гусеничной подвески и модели брони. Корпус наклоняется по нормали рельефа. Башня ограничена скоростью; вертикальный угол ствола ограничен.
- **Оружие:** фиксированный урон 40, здоровье танка 100, перезарядка 2,2 с, снаряд 110 м/с, время жизни 3 с. Проверяется весь отрезок перемещения с выбором первого попадания. Пересечение с землёй точно вычисляется по плоскостям треугольного heightfield. Отдельная проверка от основания ствола до дульного среза препятствует выстрелу через стену, в которую вошёл ствол. Урона по площади нет.
- **Разрушение:** 120 HP; целое → повреждённое → обломки. Три попадания уничтожают здание. При 0 HP сервер полностью удаляет его коллайдер. Обломки декоративные и проходимые. Каменные блоки не разрушаются; маленькие кусты — декоративные.
- **Бой:** каждый сам за себя, K/D в HUD; возрождение через 5 секунд в свободной точке с предпочтением удалённых от противников мест. Защита появления 2 секунды снимается при выстреле или запуске дрона.
- **Клиент:** Three.js, оригинальные примитивные модели, тени и простые частицы; 30 кадров/с, стартовое поле 15 кадров/с, скрытая вкладка не рендерится. Миникарта показывает рельеф и свои аппараты; противников нужно искать визуально. Имена противников скрываются за рельефом и целыми укрытиями.
- **Пределы:** одна карта, один тип танка, до четырёх мест с учётом временно отключённых игроков. Нет аккаунтов, прогрессии, магазина, ботов и матчмейкинга. Сессия длится до остановки сервера.

Игровые параметры находятся в `src/shared/config.ts`, схема карты — в `src/shared/map.ts`. После изменения параметров выполнить `npm run build` и перезапустить сервер; у всех клиентов должна быть новая сборка.

## Сценарий проверки двумя игроками

1. Запустить хост; подключить Alpha и Bravo с двух компьютеров. У обоих должны быть два игрока в списке. Доехать к перекрёстку посёлка, чтобы увидеть друг друга.
2. По очереди двигаться, поворачивать корпус и мышью доворачивать башню, поднять/опустить ствол. Другой игрок должен видеть эти изменения; за холмом танк и его метка должны скрываться.
3. Дождаться окончания защиты появления. Попасть один раз в Bravo: у владельца и наблюдателя здоровье должно стать 60. Ещё два попадания уничтожают танк и увеличивают счёт Alpha. Через 5 секунд Bravo появляется в свободном месте.
4. Стрелять три раза в одно здание. После первого попадания видны повреждения; после третьего — обломки у обоих игроков. Проехать через прежнее место здания. Подключить третью вкладку/компьютер: здание должно сразу быть разрушено.
5. Нажать F. Владелец получает FPV-камеру; второй игрок видит летящий квадрокоптер и неподвижный танк владельца. Проверить W/S, A/D, Space/Ctrl и мышь, индикаторы времени, высоты и дальности.
6. Нажать F для возврата. Проверить перезарядку. После повторного запуска столкнуться со зданием/землёй или попасть по дрону с другого танка: дрон исчезает у обоих, владелец возвращается к танку. Уничтожить танк во время FPV и проверить выход из режима.
7. Перезагрузить одну вкладку, снова войти с её сохранённым токеном. Счёт должен сохраниться в пределах 30 секунд. Закрыть вкладку: оставшиеся игроки продолжают бой; после 30 секунд отключённое место освобождается.
8. Подключить четыре игрока; пятый получает сообщение о заполненной арене. Остановить/возобновить сервер и проверить понятный статус потери связи и автоматическое переподключение.

Фактически выполненные проверки и ограничения проверки находятся в [docs/verification.md](docs/verification.md).
